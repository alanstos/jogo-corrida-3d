<objective>
Implement the TURBO boost mechanic (FEEL-01): a one-shot speed boost activated by a touch button or keyboard, lasting 2 seconds, followed by a 5-second cooldown during which reactivation is blocked. Players see immediate visual feedback (button class changes) and feel a tangible acceleration increase from a 2.5x force multiplier applied to the car's forward thrust.

Purpose: Without turbo, the player has no agency over speed — the car moves at a constant difficulty-controlled velocity. Turbo is the first interactive momentum mechanic and is the foundation for the haptic feedback (Plan 03-05) that depends on this state transition.

Output: Working TURBO button in the touch HUD, keyboard binding (T or Space), Controls.js extended with the 'turbo' intent, Game.js running the timer-based state machine, Car.js applying the force multiplier, HUD.js reflecting state via CSS classes.
</objective>
