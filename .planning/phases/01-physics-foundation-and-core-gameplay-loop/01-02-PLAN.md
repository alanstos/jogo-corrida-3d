    - Each segment is a `THREE.Mesh` with `BoxGeometry(10, 0.1, 20)` and `MeshLambertMaterial({ color: 0x2a0055 })` (dark purple). Position them in a contiguous line from z=0 down the negative-Z direction: segment i at z = -i * SEGMENT_LENGTH. Store in `this._segments` array.

    - Spawn logic: every `1.5 / speedMultiplier` seconds, pick an inactive obstacle, randomize x ∈ {-3, 0, 3} (three lanes), position at z = -(SEGMENT_COUNT * SEGMENT_LENGTH) + 10 (just visible at far end), mark active, sync mesh visibility (TRACK-02 — random obstacles).

    **`reset()` method:** Reset `_elapsedTime = 0`, `_scrollSpeed = 20`, reset all segment positions to initial layout, deactivate all obstacles. Used by Game.reset() in T3.

    **`getDistanceTraveled()` method:** returns `this._elapsedTime * this._scrollSpeed` (cumulative — used for score in T3).

    **`follow(carMesh, deltaTime)` method:**
    ```
    const targetPos = carMesh.localToWorld(this._offset.clone());

    this.instance.position.lerp(targetPos, alpha);
    this.instance.lookAt(carMesh.position);
    ```
    Use `carMesh.localToWorld(this._offset.clone())` so the camera trails behind the car relative to its current orientation. The `.clone()` is critical — `localToWorld` mutates in place.
