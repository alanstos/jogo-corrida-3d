    Implement `_tick(timestamp)` with **MANDATORY ORDER** (this is a code invariant — comment each step):
    1. `this._rafHandle = requestAnimationFrame(ts => this._tick(ts))`
    2. `const rawDelta = (timestamp - this._lastTime) / 1000; this._lastTime = timestamp; const safeDt = Math.min(rawDelta, 0.05)` (PITFALLS #5)

    4. `const intent = this.controls.getIntent()` — read input

    6. `this.physicsWorld.step(safeDt)` — step physics

    8. `this.renderer.render(this.scene, this.camera)` — render LAST

    Implement `stop()`: `cancelAnimationFrame(this._rafHandle)` (PITFALLS #16) — used by Game-Over reset in 01-02.

    Add a diagnostic block: log `this.car.body.position` every 60 frames (use a frame counter) so the developer can see y stabilize above 0 in the console.
