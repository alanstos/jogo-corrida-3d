# Phase 02 Plan 01: Storage Module (safeGet / safeSet)

## Goal

`game/Storage.js` exists and exports `safeGet` / `safeSet` with correct null-check and QuotaExceededError handling, so any subsequent plan can import it without modification.

## Tasks

### T1: Create `game/Storage.js` with safeGet and safeSet

**Files:** `game/Storage.js`

**What:** New standalone ES module exporting two named functions. No side effects on import.

**How:**

1. Create the file at `game/Storage.js`.
2. Export `safeGet(key, defaultValue)`:
   - Call `localStorage.getItem(key)` inside a `try/catch`.
   - Check `raw === null` before calling `JSON.parse(raw)` — if `null`, return `defaultValue` immediately. This avoids `JSON.parse(null)` returning `null` instead of the default.
   - If `JSON.parse` throws (corrupt value), catch and return `defaultValue`.
   - The outer `try` also covers the Safari private-browsing case where `localStorage.getItem` itself throws.
3. Export `safeSet(key, value)`:
   - Wrap `localStorage.setItem(key, JSON.stringify(value))` in a `try/catch`.
   - On any exception (QuotaExceededError, Safari private-mode) — silently swallow the error. Loss of the highscore save is acceptable degradation; do not propagate.
4. No default export. Named exports only: `export function safeGet(...)` and `export function safeSet(...)`.

**Verify:** Open browser DevTools console and run:

```
import('/game/Storage.js').then(m => {
  m.safeSet('__test', 42);
  console.assert(m.safeGet('__test', 0) === 42, 'round-trip ok');
  console.assert(m.safeGet('__missing', 99) === 99, 'default ok');
  localStorage.setItem('__corrupt', '{bad json}');
  console.assert(m.safeGet('__corrupt', -1) === -1, 'corrupt fallback ok');
  localStorage.removeItem('__test'); localStorage.removeItem('__corrupt');
  console.log('Storage.js OK');
});
```

All three asserts must pass with "Storage.js OK" logged.
