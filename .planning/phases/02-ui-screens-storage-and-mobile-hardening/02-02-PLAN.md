# Phase 02 Plan 02: Menu Overlay + INICIAR Wiring + HUD/Touch Hidden on Menu

## Goal

The game opens to a visible menu overlay (logo, INICIAR button, RECORD line hidden until first save); the HUD and touch controls are hidden until INICIAR is pressed; pressing INICIAR hides the menu and starts the game loop.

## Tasks

### T1: Add menu overlay HTML and hide HUD/touch controls on load

**Files:** `index.html`

**What:** Add `#menu` overlay div above the existing overlays; add `.hidden` to `#hud` and `#touchControls` so they are invisible while the menu is showing.

**How:**

1. Add `class="hidden"` to the existing `<div id="hud" ...>` element (currently has no `.hidden`). This hides the HUD on page load; `game.start()` will reveal it.
2. Add `class="touch-controls hidden"` to the existing `<div id="touchControls" ...>` element (currently has `class="touch-controls"` only).
3. Insert a new `<div id="menu" class="overlay" aria-hidden="false">` block immediately before the existing `<div id="gameOver" ...>`. The menu does NOT start hidden — it is visible on page load (opposite of gameOver which starts with `.hidden`).
4. Inside `#menu`, place a single `<div class="overlay-inner">` with:
   - `<h1 class="menu-logo">RETRO RACER 3D</h1>`
   - `<p id="menuRecord" class="menu-record hidden">RECORDE: <span id="menuRecordValue">0</span></p>` — starts hidden per D-06; revealed when a record exists
   - `<button id="btnIniciar" type="button">INICIAR</button>`
5. No difficulty buttons yet — those are added in Plan 03. The INICIAR button is wired in T3 of this plan.

### T3: Wire INICIAR in `main.js` and add `returnToMenu()` to `Game.js`

**Files:** `main.js`, `game/Game.js`

**What:**
- `main.js` no longer auto-starts the game; it wires INICIAR to call `game.start(difficulty)` and reveal HUD/touch.
- `Game.js` gains a `returnToMenu()` method that cancels RAF and shows the menu; `start()` accepts a difficulty object parameter (defaulting to Médio values); `_tick()` passes `this._speedMultiplier` instead of `1.0`.

**How — `main.js`:**

1. Remove the `game.start()` call from `init()`.
2. After constructing `game`, read DOM refs: `const menuEl = document.getElementById('menu')`, `const hudEl = document.getElementById('hud')`, `const touchEl = document.getElementById('touchControls')`, `const btnIniciar = document.getElementById('btnIniciar')`.
3. Add a `pointerup` listener on `btnIniciar`:
   - `menuEl.classList.add('hidden'); menuEl.setAttribute('aria-hidden', 'true');`
   - `hudEl.classList.remove('hidden');`
   - `touchEl.classList.remove('hidden');`
   - Call `game.start({ speedMultiplier: 1.0, obstacleCount: 8 })` — hardcoded Médio defaults here; Plan 03 will pass the selected difficulty instead.
4. `init()` must not call `game.start()` anywhere — the Game constructor runs but RAF does not start.

**How — `game/Game.js`:**

1. Change `start()` signature from `start()` to `start({ speedMultiplier = 1.0, obstacleCount = 8 } = {})`.
2. Inside `start()`, add `this._speedMultiplier = speedMultiplier;` before the RAF call. Also store `this._speedMultiplier = 1.0` in the constructor (initialize to default so `_tick()` never reads undefined).
3. In `_tick()` Step 7, change `this.track.update(safeDt, 1.0, ...)` to `this.track.update(safeDt, this._speedMultiplier, ...)`.
4. Add a `returnToMenu()` method to `Game`. This method must:
   - Call `cancelAnimationFrame(this._rafHandle); this._rafHandle = null;`
   - Set `this.state = 'MENU';`
   - Hide game-over overlay: `this._gameOverEl.classList.add('hidden'); this._gameOverEl.setAttribute('aria-hidden', 'true');`
   - NOT reset car/track positions (per RESEARCH §6 — reset happens at next `start()`, not at menu-show time)
   - NOT destroy controls (unlike `stop()` which calls `this.controls.destroy()`)
5. Add DOM refs in the constructor for the menu overlay and HUD/touch: `this._menuEl = document.getElementById('menu')`, `this._hudEl = document.getElementById('hud')`, `this._touchEl = document.getElementById('touchControls')`.
6. Update `returnToMenu()` to also: `this._menuEl.classList.remove('hidden'); this._menuEl.setAttribute('aria-hidden', 'false'); this._hudEl.classList.add('hidden'); this._touchEl.classList.add('hidden');`.
7. Re-wire the existing `#retryButton` listener from `this.reset()` to `this.returnToMenu()` (D-04: both RETRY and MENU go to menu). The existing retry button label change is handled in Plan 04 alongside the full game-over revamp.

**Verify:** Open the page. Must see menu overlay immediately. Press INICIAR — menu disappears, HUD and touch controls appear, car starts moving. The game loop is running correctly. After game over (hit an obstacle), press RETRY — game should return to menu (HUD/touch hidden again, menu visible). Note: game-over screen still has only the old RETRY button at this stage; the full revamp is Plan 04.
