## v1 Requirements (All Complete)

### Physics & Movement

- [x] **PHYS-01**: Carro avança automaticamente com física Cannon-es (mass > 0, allowSleep: false, applyLocalForce) — v1.0
- [x] **PHYS-02**: Carro vira à esquerda/direita via torque com damping — v1.0
- [x] **PHYS-03**: Câmera chase cam em terceira pessoa com lerp suave atrás do carro — v1.0
- [x] **PHYS-04**: Ground plane física impede o carro de cair (Plane rotacionado -π/2) — v1.0

### Controls

- [x] **CTRL-01**: Botões touch esq/dir fixos na base da tela (pointer events, touch-action: none) — v1.0
- [x] **CTRL-02**: Teclado (setas/WASD) funciona para testar no desktop — v1.0
- [x] **CTRL-03**: Botões com feedback visual ao pressionar (highlight/scale CSS) — v1.0

### Track & Obstacles

- [x] **TRACK-01**: Pista reta com rolagem infinita via pool de segmentos reciclados — v1.0
- [x] **TRACK-02**: Obstáculos estáticos (caixas/barreiras) gerados aleatoriamente na pista — v1.0
- [x] **TRACK-03**: Limites laterais da pista visíveis (bordas coloridas ou geometria) — v1.0
- [x] **TRACK-04**: Velocidade da pista aumenta progressivamente com o tempo — v1.0

### Gameplay Loop

- [x] **GAME-01**: Colisão com obstáculo termina a corrida (game over) — v1.0
- [x] **GAME-02**: Score aumenta com a distância percorrida — v1.0
- [x] **GAME-03**: Tela de game over exibe score com botão Retry (sem reload de página) — v1.0
- [x] **GAME-04**: Retry reseta o estado do jogo em < 500ms — v1.0

### HUD

- [x] **HUD-01**: Score visível durante o jogo (pixel font) — v1.0
- [x] **HUD-02**: Velocidade atual exibida (numérica) — v1.0

### UI Screens

- [x] **UI-01**: Tela inicial com botão INICIAR e seletor de dificuldade (Fácil/Médio/Difícil) — v1.0
- [x] **UI-02**: Dificuldade afeta velocidade base e densidade de obstáculos — v1.0
- [x] **UI-03**: Tela de game over com score e botão Retry — v1.0

### Storage

- [x] **STOR-01**: Melhor score salvo no localStorage com safeGet/safeSet (try/catch) — v1.0
- [x] **STOR-02**: Recorde exibido na tela inicial — v1.0

### Performance

- [x] **PERF-01**: Renderer com antialias: false e shadowMap: false em mobile — v1.0
- [x] **PERF-02**: Pixel ratio limitado a Math.min(devicePixelRatio, 2) — v1.0
- [x] **PERF-03**: Materiais MeshLambertMaterial ou MeshToonMaterial (sem PBR) — v1.0
- [x] **PERF-04**: Loop pausado com visibilitychange (evita delta explosion) — v1.0
